# DraftShopper

A small SwiftUI shop app that [DraftVM](https://draftvm.com) uses to test AI agents on live iPhone Simulators: an agent opens a product, picks a size and adds it to the bag, the way a person would.

**For testing only.** DraftShopper is not a real shop. The brands, products, prices and reviews are made up, nothing can be bought, and no payment is taken or sent anywhere. Its catalogue is bundled in the app (SwiftData), and it sends nothing anywhere.

## Run it

Open `DraftShopper.xcodeproj` in Xcode and run the `DraftShopper` scheme on an iPhone Simulator.
